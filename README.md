# 巷口鍋貼舖（暫名）0.1 原型

第一人稱站在大鐵鍋前煎鍋貼。這一版只驗證一件事：**玩家會不會看隊伍決定這一鍋下幾顆**。

## 執行

```bash
npm install
npm run dev      # 開發，瀏覽器開 http://localhost:5173
npm test         # 單元測試
npm run build    # 輸出到 dist/
```

## 怎麼玩

| 動作 | 滑鼠 | 鍵盤 |
|---|---|---|
| 放鍋貼 | 點生餃盤、點鍋子、按 +1 / +5 | `1`、`5` |
| 拿出來 | 按 −1 | `Backspace` |
| 淋粉漿水・蓋鍋 | 點水壺或鍋蓋、按右下大按鈕 | 空白鍵 |
| 鏟出 | 收乾時點鍋子或按大按鈕 | 空白鍵 |
| 清鍋 | 燒焦時點鍋子或按大按鈕 | 空白鍵 |
| 出餐 | 點客人（保溫台要夠） | |

## 程式在哪裡

只有六個檔，規則和畫面分開，其他不再分層：

| 檔案 | 內容 | 什麼時候改它 |
|---|---|---|
| `src/balance.json` | 所有數值：鍋子容量、蒸幾秒、完美時間窗、保溫幾秒、客人多久來一次、單價 | 調手感、調難度 |
| `src/pan.ts` | 大鐵鍋：排鍋 → 蓋鍋蒸 → 收乾 → 鏟出／燒焦 → 清鍋 | 改煎鍋貼的規則 |
| `src/shop.ts` | 整間店：鍋子、保溫台、客人、統計。畫面要做的事都呼叫這裡 | 改保溫台、客人、出餐、算錢 |
| `src/GameScene.ts` | Phaser 畫面：畫圖、按鈕、點擊 | 改畫面、操作、文字 |
| `src/music.ts` | 背景音樂與畫面下方的音樂列 | 改播放方式、音樂列 |
| `src/main.ts` | 啟動 Phaser 和音樂 | 幾乎不用動 |

規則（`pan.ts`、`shop.ts`）不碰 Phaser，所以可以直接寫測試（`tests/`）。
畫面每一幀從 `shop` 讀資料重畫，不另外存一份狀態，改規則時畫面會自己跟上。

## 背景音樂

- **加歌**：把音檔（mp3、m4a、ogg、wav）丟進專案根目錄的 `music/`，重新整理就會出現在畫面下方的選單，歌名就是檔名。
- 同一首有 mp3 和 ogg 兩份（例如 `music_day.mp3`、`music_day.ogg`）會合成一首，優先放 mp3。
- 選「隨機播放」一首放完換下一首；選某一首就是單曲循環。選哪首、音量、靜音會記在這台裝置。
- 瀏覽器規定要有操作才能出聲，所以第一次點畫面或按鍵時才開始放。
- iPhone 不讓網頁調音量，音量拉桿在 iPhone 上沒作用，靜音有用。

## 除錯

- 網址加 `?speed=5` 會快轉 5 倍。
- 瀏覽器 console 打 `shop` 可以看到整間店的狀態，也能直接改，例如 `shop.pan.timer = 5`。

## 美術

`public/art/` 是佔位用的像素圖（320×180，遊戲裡放大 4 倍），由 `tools/placeholder_art.py` 產生（需要 Python 和 Pillow）。
所有圖層共用同一個座標系，換正式美術時照同樣尺寸、同樣位置畫就能直接替換。
